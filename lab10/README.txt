Формат файла matrix.txt
- Первая строка: два целых положительных числа (количество строк и столбцов).
- Далее следует ровно указанное количество строк, в каждой ровно указанное количество целых чисел, разделенных пробелами.
- Кодировка файла: UTF-8.

Индивидуальный вариант №2
Условие: Сумма отрицательных элементов.
Реализация: Функция `selected_sum(matrix)` в файле `files_lab.py`.
Результат для matrix.txt: -8 (так как -2 + (-6) = -8).

Ответы на вопросы:

1. Отличие ошибок формата от ошибок доступа.
-Ошибки формата (ValueError): возникают, когда файл успешно открыт и прочитан, но его содержимое не соответствует ожидаемому шаблону (например, буквы вместо цифр, неверное количество столбцов, пустой файл).
-Ошибки доступа (FileNotFoundError, OSError, UnicodeError): возникают на уровне операционной системы или ввода-вывода. Файл может отсутствовать, быть заблокированным другой программой, или у пользователя нет прав на чтение. Также сюда относится неверная кодировка.

2. Почему отчёт открывается для записи только после проверки входа?
Если открыть файл отчета в режиме `"w"` (запись) до чтения исходного файла, то старый `report.txt` будет немедленно стерт (обнулен). Если после этого при чтении `matrix.txt` произойдет ошибка (например, он поврежден), мы потеряем и старый отчет, и не создадим новый. 
Чтобы этого избежать, по условию задачи мы сначала полностью проверяем входные данные, производим все вычисления в памяти, и только если всё прошло успешно — открываем `report.txt` на запись для сохранения результата.

3. Проверка сохранности старого отчета.
Вручную: был создан файл `report.txt` с текстом "Старый отчет". В `matrix.txt` была внесена ошибка (буква вместо числа). При запуске `main.py` программа вывела "Ошибка формата данных", а файл `report.txt` сохранил текст "Старый отчет" без изменений.
